## 15. 검증 기록

`charter.md`의 SC/FR ID를 그대로 쓰며, 값만 적고 판정은 하지 않는다. 각 ID의 가장
최근 값은 이 표에 있고, 과거 추이는 지난 기록 파일에 있다.

`방법` 칸은 `타입·컴파일` / `테스트(스펙 확인)` / `테스트(미확인)` / `실행` /
`정적분석` / `LLM 검토` 중 하나다. 에이전트가 작성한 테스트를 에이전트가 통과시킨 것은
`테스트(미확인)`이고, 그것만으로 `SC-nn`을 판정하지 않는다.
